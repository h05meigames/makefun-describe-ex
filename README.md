## The word

**Predecessor**

Corporate-speak for the person who held the job before you — the previous holder of the "partner" position. The ex was not the one, just the one before the one.

## How it works

`main.ts` (Node 22+) deterministically writes the single word to `/output/entry.txt` and prints the same word to stdout. It validates the word first: exactly one word, 1–111 characters, no whitespace.

```sh
node main.ts
# Predecessor
```

The entry text is also shipped as [`entry.txt`](entry.txt), byte-identical to the program's output.
