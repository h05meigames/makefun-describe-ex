## How it works

`main.ts` (Node 22+) deterministically writes the single word to `/output/entry.txt` and prints the same word to stdout. It validates the word first: exactly one word, 1–111 characters, letters only, and never the round-1 word.

```sh
node main.ts
# Placeholder
```

The entry text is also shipped as [`entry.txt`](entry.txt), byte-identical to the program's output.
